Projetos desenvolvidos durante a formação da **42 São Paulo**, cobrindo toda a trilha de Python: desde os fundamentos de sintaxe e coleções até Programação Orientada a Objetos avançada, manipulação de arquivos, design patterns, engenharia de pacotes e arquitetura de software.

---

## 📚 Sobre a trilha

Os módulos **Python Module 00 ao 09** fazem parte do currículo da **42** para domínio da linguagem Python e boas práticas de desenvolvimento (seguindo padrões como **PEP 8 / `flake8`** e tipagem estática com **`mypy`**).

A jornada evolui de forma incremental:

- **Módulos 00 — 03:** Fundamentos da linguagem, POO, tratamento de exceções e estruturas de dados (`list`, `tuple`, `set`, `dict`).
- **Módulos 04 — 06:** Manipulação de arquivos/streams, polimorfismo avançado, interfaces abstratas e arquitetura de pacotes.
- **Módulos 07 — 09:** Design patterns, metaprogramação, decorators, generators, validação de dados e sistemas completos.

---

## 🗂️ Visão Geral dos Módulos

| Módulo | Tema Principal | Conceitos-Chave |
| :--- | :--- | :--- |
| **Module 00** | Fundamentos do Python | Sintaxe, tipos básicos, strings, condicionais, loops, funções e `sys.argv` |
| **Module 01** | Programação Orientada a Objetos | Classes, objetos, `__init__`, encapsulamento (`@property`), herança e polimorfismo |
| **Module 02** | Tratamento de Erros e Exceções | `try / except / else / finally`, exceções customizadas e programação defensiva |
| **Module 03** | Coleções e Estruturas de Dados | `list`, `tuple`, `set` (`union`, `intersection`, `difference`), `dict` e comprehensions |
| **Module 04** | Manipulação de Arquivos e Streams | `open()`, gerenciadores de contexto (`with`), leitura/escrita e tratamento de I/O |
| **Module 05** | Polimorfismo e Interfaces | Classes Abstratas (`abc.ABC`), `@abstractmethod`, duck typing e composição |
| **Module 06** | Módulos, Pacotes e Imports | Estruturação de pacotes (`__init__.py`), imports relativos/absolutos e namespaces |
| **Module 07** | Design Patterns e Arquitetura | Padrões criacionais, estruturais e comportamentais aplicados em Python |
| **Module 08** | Recursos Avançados e Metaprogramação | Decorators, iteradores, generators (`yield`), closures e `*args` / `**kwargs` |
| **Module 09** | Engenharia de Dados e Validação | Type hints avançados, dataclasses/modelos, parsing e pipelines robustos |
